# WorldPulse Football — Android v2.4.0

تطبيق عربي خفيف لمباريات ونتائج **7 بطولات فقط**: دوري نجوم العراق، LaLiga، الدوري الإنجليزي الممتاز، دوري أبطال أوروبا، كأس العالم، كأس أمم أوروبا، كأس أمم آسيا.

## الهوية الرياضية الجديدة
- لوحة Adobe المختارة: `#2B3D54` أزرق بحري، `#2C5B61` أزرق مخضر، `#247065` أخضر داكن، `#60A65F` أخضر، `#FFEC97` ذهبي فاتح.
- أيقونات Vector أصلية صغيرة للحركة بين الصفحات (المنزل، كرة القدم، الكأس، النجمة، إعدادات).
- شريط تنقل وبطاقات رياضية حديثة وواجهة RTL أصلية.
- وضع داكن يتبع إعداد الهاتف تلقائياً مع تباين نصوص واضح، بلا صور محمّلة من الإنترنت.
- تحديثات النتائج أثناء فتح التطبيق تحافظ على موضع التمرير عند وصول البيانات.

## نتائج ومباريات وترتيب
- `backend/sports_refresh.py` يجلب المباريات المعلنة ويحدّث `docs/fixtures.json` بجدولة GitHub Actions **كل 5 دقائق تقريباً** (قد تتأخر).
- Android يتحقق من الملف كل دقيقة أثناء الاستخدام فقط. لا يدّعي توفير بث فوري أو خدمة Push أثناء إغلاق التطبيق.
- `backend/collector.py` يجمع الأخبار العربية والترتيب بشكل مستقل كل ساعة. ترتيب الدوري هو فقط ما يرجعه المزود، مع وقت التحديث.
- تفاصيل المباراة: أحداث الأهداف والبطاقات والتبديلات والإحصاءات والتشكيلات، **عند توفرها في مصادر مرخصة**.
- بيانات الجولة 13 للدوري العراقي 5–8 نوفمبر 2026 احتياطية موثقة محدودة الصلاحية؛ لا تقدم نتائج مباشرة.
- ESPN وTheSportsDB عامتان وغير مضمونتي التغطية؛ يمكن إضافة مفتاح `API_FOOTBALL_KEY` على GitHub لتحسينها. لا يُخزّن داخل APK.

## تحليل APK المرجعي
تم فحص مكونات Dex وموارد APK المرجعي؛ وجود Firebase Messaging وWorkManager وWebSocket يدل على دعم مزامنة وإشعارات لكنه لا يكشف بمفرده دورة التحديث الفعلية. لا ننسخ شيفرة التطبيق المرجعي أو علاماته أو مفاتيحه. التفاصيل: `docs/reference-apk-study.md`.

## البناء
من GitHub Actions اختر **Build Android APK** لتحميل ملف Debug APK. الحد الأدنى Android 8.0، ويلزم توقيع خاص للإصدار المنشور في المتجر.
